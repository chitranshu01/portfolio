## 🌟 Overview

A modern, responsive, high-performance developer portfolio built with semantic HTML5, modern vanilla CSS3 (Obsidian Dark / Cyber-Glass design system), and vanilla JavaScript. Features rich micro-animations, theme toggling, interactive filtering, and an AI workflow simulator.

### 🚀 Highlights
- **Interactive Hero Profile Card:** Modern glassmorphism card highlighting core proficiencies and social links.
- **Dynamic Typing Animation:** Live-typing effect featuring key architectural specialties.
- **Interactive Skills Filter:** Category-based filtering (Agentic AI, AI Engineering, Backend, Languages, Frontend, Databases & Cloud).
- **Interactive LangGraph Simulator:** Visual step-by-step pipeline demonstrating autonomous agent flows (Router &rarr; Tavily &rarr; Workers &rarr; Reducer).
- **Academic Timeline:** Comprehensive educational history featuring B.Tech IT at BIET Jhansi and schooling from Central Hindu Boys School (BHU).
- **One-Click Contact & Copy:** Clipboard buttons and direct contact submission form with instant feedback.

## 🛠️ Tech Stack & Design System

- **Frontend:** HTML5, Modern Vanilla CSS3 (Custom Design Tokens, Flexbox & CSS Grid, Glassmorphism, CSS Variables), Vanilla ES6+ JavaScript
- **Icons & Typography:** [Lucide Icons](https://lucide.dev/), Google Fonts (*Plus Jakarta Sans*, *JetBrains Mono*, *Space Grotesk*)
- **Performance:** Zero bulky external UI framework dependencies, fast load times, and fluid responsive layouts across mobile, tablet, and desktop.

## 🏃 Running Locally

To run this portfolio locally without any build tools or dependencies:

### Using Python:
```bash
python -m http.server 8080
```
Then open your browser at `http://localhost:8080`.

### Using Node.js / npx:
```bash
npx serve .
```
